# LeetCode-Style Coding Platform AI-integrated| MERN Stack

- **Implemented** a full-stack AI-integrated coding practice platform inspired by LeetCode, featuring real-time code execution powered by the Judge0 API.  
- **Improved** the interactive coding environment using the Monaco Editor by utilizing syntax highlighting, auto-completion, and live error detection to deliver a better developer experience.  
- **Integrated** an AI-powered coding assistant to help users debug, explain code, suggest optimizations, and generate solutions in real time, enhancing learning and problem-solving efficiency.  
- **Employed** secure  authentication mechanisms using JWT, bcrypt, and Redis session caching, ensuring fast login while preventing token misuse.  
- **Established** an AI-enhanced role-based access system enabling admins to add, update, and delete coding problems, while users solve, submit, and track progress in real time.  
- **Generated**  problem-solving analytics that allow users to view solved problems, submission status, and coding history with persistent storage in MongoDB.  
- **Fine-tuned** backend performance and reliability with rate limiting, API validation, and a secure middleware architecture.
